This document serves as the single source of truth for the LEVY digital ecosystem. It is an operational CSS framework designed for extreme structural rigor, explicitly optimized for multi-device performance and AI development ingestion.

1. Edit Globally

Modify the design tokens (colors, curves, typography) directly in the :root CSS variables. Changes will instantly propagate across all components and devices flawlessly.

2. Copy Structurally

Do not alter the HTML structural classes. To build new interfaces, instruct AI agents to map elements directly to the responsive 5-column grid components shown below.
